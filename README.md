# 📊 Bank Loan Analytics

## 📌 Project Overview

This project analyzes **bank loan data** to understand loan applications, funded amounts, repayment performance, loan status, borrower characteristics, and key financial metrics.

The objective is to transform raw loan data into meaningful insights that can help understand **loan performance, customer behavior, and lending trends**.

## 🎯 Business Objectives

- Analyze total loan applications and funded amounts.
- Track loan repayment and payment performance.
- Compare **Verified vs Non-Verified** loan payments.
- Analyze loan performance by **grade and sub-grade**.
- Identify trends by **state and month**.
- Understand the relationship between **home ownership and loan performance**.
- Monitor key loan KPIs using interactive dashboards.

## 🛠️ Tools & Technologies

- **Excel** – Data cleaning and preparation
- **MySQL** – Data storage, querying, and analysis
- **Power BI** , **Tableau**– Interactive dashboard and visualization

## 📈 Key KPIs

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI
- Good Loan Percentage
- Bad Loan Percentage
- Loan Status Distribution

## 🔍 Analysis Performed

### 1. Loan Application Analysis

Analyzed loan applications based on:

- Loan status
- Loan grade
- Loan purpose
- Employment information
- Home ownership

### 2. Financial Analysis

Analyzed:

- Funded loan amount
- Total payment received
- Interest rate
- Revolving balance
- Debt-to-income ratio

### 3. Geographic & Time Analysis

Analyzed loan trends by:

- State
- Month
- Year

### 4. Loan Verification Analysis

Compared total payments between:

- Verified customers
- Non-Verified customers

### 5. Grade & Sub-Grade Analysis

Analyzed revolving balance and loan performance across different:

- Loan grades
- Sub-grades

## 📊 Dashboard

The Power BI dashboard provides an interactive view of:

- Overall loan KPIs
- Loan status
- Loan applications by month
- Loan distribution by state
- Grade and sub-grade performance
- Home ownership analysis
- Verification status
- Loan purpose

Users can interact with the dashboard using **slicers and filters** to explore different segments of the data.

## 💡 Key Insights

The analysis helps identify:

- Changes in loan applications over time.
- Differences in loan performance across grades.
- Geographic patterns in loan applications.
- Payment differences between verified and non-verified customers.
- Customer characteristics associated with different loan outcomes.
- Areas where loan performance can be monitored more closely.
